Tranient Cloud Modeling

The above animation shows the results of a simulation I created. This simulation takes a binary mask representing a cloud, and maps it over a field of heliostats. Input Variables include cloud size, velocity, time of day, and time step. The script I wrote maps each heliostat based on position and assigns it a shading value based on the cloud mask. It then uses solarpilot api to change normal irradiance values to reflect shading. By running the simulation over a through time, we get a visual showing how the flux on the reciever changes as the cloud passes over the field. The leftmost image shows the cloud map and the efficiency of each heliostat as well as the sun vector. The middle images shows the resulting heatmap of flux on the central reciever. The leftmost image shows the change in azimuth angle for each heliostat under the current aiming strategy.
