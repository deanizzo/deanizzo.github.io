Overview

Prometheus is an NREL research project to optimize the performance of a solar power tower energy plant. This type of plant generates energy by using a field of mirrors to direct sunlight up to a central reciever. The driving problem is how to aim these heliostats to balance power output and reciever lifetime. My work involves modeling the the plant using Pyton and C++ to better understand its performance.

Transient Cloud Conditions (Presented at SolarPACES)

The above animation shows the results of simulating a cloud passing over a heliostat field, affecting the total flux. I created this simulation using the solarPILOT api and writing my own script to impose cloud conditions. We represent the cloud first with a binary matrix which is then converted into a coordinate map through user input shifting and scaling values. Each heliostat is mapped to this coordinate system to determine wheather it is being shaded or not. If a heliostat is shaded, it's "soiling value" is modified through the api and its flux contribution is recalculated to reflect lower irradiance. By doing this for every heliostat, we get a realistic image of flux on the reciever when a cloud is blocking sunlight. We can then create a time step by shifting the mask coordinate system over by a user specified "wind value", updating solar position in the api, and resimulating while storing data at each iteration. The final result is an animation of reciever flux over time as a cloud passes over the field, which is the animation pictured above.
