## 🎯 Project 1: **Ping Pong Playing Robotic Arm**
**Summary:**  
Designed and built a robotic arm capable of detecting ping-pong ball trajectories and returning shots using real-time control and predictive modeling.

**Highlights**
- Implemented quadratic trajectory fitting to estimate ball path  
- Built servo control interface using Raspberry Pi + PCA9685 driver  
- Developed OpenCV-based ball detection and tracking  
- Designed arm structure in CAD and integrated kinematic analysis  

**Technical Details**
- *Control:* PID tuning for servo response  
- *Modeling:* Quadratic regression for projectile motion  
- *Software:* Python, OpenCV, NumPy  
- *Hardware:* Raspberry Pi, servos, camera module
